# Go IDE (VS Code Edition) на базе nativeForms

Полнофункциональная среда разработки для Go с интерфейсом в стиле **Visual Studio Code**, построенная на актуальной версии библиотеки `github.com/banditmoscow1337/nativeForms`.

## Ключевые возможности

### 1. VS Code-подобный интерфейс (Workbench)
- **Единое главное меню (`ui.MenuBar`) без лишнего topbar и без трея**:
  - Развёрнутые непрозрачные выпадающие меню `Файл`, `Правка`, `Вид`, `Переход`, `Go`, `Отладка` и `Терминал` с иконками и горячими клавишами.
  - Встроенные в `MenuBar` кнопки быстрых действий: `Run`, `Build`, `Test`, `gofmt`, `Debug`, `Stop`, `Срез (1/2/3)`, `Версии Go`, `Команды (F1)` и `Тема (F2)`.
- **Редактирование нескольких файлов рядом — 1 / 2 / 3 среза (VS Code Split Editor Right)**:
  - Разделение области редактора на `1`, `2` или `3` независимых вертикальных среза рядом (`Ctrl+\`, `Ctrl+1`, `Ctrl+2`, `Ctrl+3`).
  - Синхронизация изменений буфера, индикаторов несохранённых файлов и точек останова между всеми срезами.
- **Визуальный и интерактивный скроллбар + плавная 120 Гц прокрутка**:
  - Полноценный вертикальный и горизонтальный скроллбар в `CodeEditor` с отображением текущего положения в файле, маркерами текущей строки курсора и точек останова, а также перетаскиванием ползунка мышью.
  - Плавная интерполяция прокрутки (`120 Гц`), кэширование разметки строк и пакетирование событий прокрутки на macOS, Linux (X11/Wayland) и Windows.
- **Управление вкладками**:
  - Закрытие только сохранённых файлов (`Ctrl+Alt+W`) и закрытие всех открытых файлов (`Ctrl+Shift+W`) через меню `Файл`, панель `ОТКРЫТЫЕ РЕДАКТОРЫ`, контекстное меню вкладок и палитру команд (`F1`).
- **Автоматический поиск, скачивание и переключение версий Go SDK и инструментов**:
  - Автопоиск установленных Go SDK и утилит (`gopls`, `dlv`, `goimports`, `staticcheck`, `gofmt`) по всем стандартным путям (`PATH`, `GOROOT`, `GOPATH`, `GOBIN`, `~/sdk`, `~/.goide/sdk`, `~/.goide/tools`).
  - Автоматическое скачивание и распаковка архивов Go SDK с `go.dev/dl` в `~/.goide/sdk/<version>` и установка инструментов через `go install <pkg>@<version>`.
  - Ручное переключение активной версии Go и версий инструментов из боковой панели `Инструменты Go` и модального менеджера версий.
- **Системный терминал (`zsh` / `bash` / `sh` / `pwsh` / `powershell` / `cmd`)**:
  - Выполнение любых системных команд, пайплайнов, `git`, `ls`, скриптов и `go` в выбранной системной оболочке.
  - Поддержка смены рабочей директории (`cd`), переключения оболочки, интерактивной передачи `stdin` запущенному процессу и автоматического разбора ошибок компилятора.

## Запуск

```sh
# Интерактивный запуск с открытием модуля:
go run ./cmd/goide_app /absolute/path/to/module

# Запуск в текущей директории со светлой темой VS Code Light+ и масштабом 1.25x:
go run ./cmd/goide_app -project . -light -scale 1.25

# Headless-проверка рендеринга и сохранение скриншота (без окна ОС):
go run ./cmd/goide_app -headless -project . -screenshot goide_vscode.png
```

## Тестирование

```sh
go test ./cmd/goide/...
```
